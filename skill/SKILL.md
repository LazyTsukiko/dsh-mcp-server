# DSH 工作电脑工具使用指南

本技能描述的 `dsh` 工具集（`agent_run`、`list_sessions`、`echo`）连接的是**用户工作电脑上真实运行的 DeepSeek Harness (DSH) 智能体**，不是沙盒或模拟环境。通过这些工具执行的任务会**真实操作用户的工作电脑**：可以读写文件、执行命令、运行代码。

## 何时使用

- 用户说"在我电脑上…"、"用 DSH…"、"看看我工作电脑的会话/项目"
- 需要真实执行代码、跑测试、分析本地项目、操作本地文件
- 需要长时间运行的自动化任务（agent_run 默认最长等 15 分钟，可用 timeout_sec 调到最长 30 分钟）

## 工具选择

| 场景 | 用哪个工具 |
|---|---|
| 在电脑上执行任何任务：查询、分析、跑命令、改代码、读文件 | `agent_run`（同步执行，返回 DSH 的最终答复文本） |
| 用户问"我电脑上有哪些会话/最近干了什么" | `list_sessions`（返回会话 id、所属目录、最近活动时间） |
| 连通性测试 | `echo` |

## 使用规范

1. **多轮对话**：`agent_run` 每次返回 `session_id`。需要在同一上下文里继续追问时，把该值传入 `session_id` 参数，DSH 会带着之前的对话历史继续。首次调用不传即新建会话
2. **工作目录**：用户提到具体项目时，把项目路径传给 `cwd`；不确定就先 `agent_run` 执行"列出 D:\dsh\workspace 下的目录"确认
3. **长任务**：超过 15 分钟的任务把 `timeout_sec` 调大（上限 1800）
4. **结果转述**：把返回的答复用自己的话总结给用户，不要原样倾倒
5. **安全底线**：删除文件、覆盖代码、系统级命令等破坏性操作，先向用户确认再执行
6. **失败处理**：返回 isError 或 exit code 非 0 时如实告知用户错误内容，不要编造执行结果
